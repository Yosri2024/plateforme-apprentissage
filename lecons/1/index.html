Introduction à HTML

Bienvenue dans le module HTML

HTML (HyperText Markup Language) est le langage qui structure une page web : titres, paragraphes, listes, tableaux, liens et formulaires. Sans HTML, rien ne peut s'afficher.

Ce que vous apprendrez

  • La structure d'un document (doctype, head, body)
  • Les balises essentielles du contenu
  • Liens, images et listes
  • Les formulaires (inputs, select, textarea)
  • Sémantique : header, nav, main, footer, section

Un premier aperçu

<!DOCTYPE html>
<html>
<head> <meta charset="UTF-8"> <title>Ma page</title></head>
<body>
  <h1>Bonjour !</h1>
  <p>Ma première page web.</p>
</body>
</html>
