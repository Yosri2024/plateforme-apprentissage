Introduction à Bootstrap

Bienvenue dans le module Bootstrap

Bootstrap est un framework CSS/JS de Twitter : il fournit une grille responsive et des composants prêts à l'emploi (navbar, cartes, modals, formulaires). On assemble des interfaces propres en empilant des classes, sans écrire de CSS en face.

Ce que vous apprendrez

  • Installer Bootstrap (CDN ou local)
  • Le système de grille : container, row, col-md-6…
  • Les classes utilitaires (espacements, couleurs, affichage)
  • Les composants : boutons, cartes, navbar, modals
  • Personnaliser les couleurs et l'apparence

Un premier aperçu

<div class="row">
  <div class="col-md-6">Gauche</div>
  <div class="col-md-6">Droite</div>
</div>
