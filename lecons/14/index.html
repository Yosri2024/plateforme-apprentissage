Bien démarrer avec Flutter & Dart

Flutter est le framework cross-platform de Google : un seul code Dart pour Android, iOS, Web et Desktop, avec des interfaces compilées en natif.

🧰 Ce dont vous avez besoin

  • Le SDK Flutter (téléchargé et décompressé manuellement)
  • Les variables d'environnement configurées (PATH)
  • flutter doctor pour vérifier l'installation
  • VS Code ou Android Studio + un émulateur Android

📘 Guide officiel — installation manuelle

https://docs.flutter.dev/install/manual

Suivez la section de votre système d'exploitation (Windows, Linux, macOS…).
